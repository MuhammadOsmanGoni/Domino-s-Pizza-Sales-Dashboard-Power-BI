# Domino-s-Pizza-Sales-Dashboard-Power-BI
Interactive Power BI dashboard for analyzing Domino's Pizza sales performance, branch revenue, product performance, and sales trends.

## Project Overview

This project analyzes Domino's Pizza sales data using Power BI. The goal was to build an interactive dashboard that helps track sales performance, compare actual sales with targets, and identify top-performing products, branches, and daily sales trends.

The dashboard brings different business metrics into one place, making it easier to monitor performance and support day-to-day business decisions.

# Dashboard Highlights

- Total Sales: ₦47M
- Sales Target: ₦48M
- Total Quantity Sold: 15K
- Total Pizza Types: 16
- Total Branches: 5
- Interactive Date Filter

## Project Objectives

- Compare sales target with actual sales
- Track daily sales performance
- Monitor branch-wise revenue
- Identify top and low-performing pizzas
- Analyze daily sales trends
- Build an interactive dashboard for business reporting


## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Dashboard Features

- KPI Cards

- Daily Sales Performance

- Branch-wise Revenue

- Pizza Target vs Actual Performance

- Top Performing Pizzas

- Lowest Performing Pizzas

- Daily Sales Trend

- Daily Sales Overview

- Interactive Date Slicer

## Business Insights

- Sales reached ₦47M, finishing slightly below the ₦48M target.
- Ikoyi and Gbagada generated the highest branch revenue.
- Hot Pepperoni Feast was the best-performing pizza based on sales.
- A few pizzas did not reach their sales targets, showing room for improvement.
- Daily sales changed throughout the reporting period, with stronger performance on some days than others.
